# Tutorial: How to Build RAG AI Agents with TypeScript

Link to tutorial: [https://www.freecodecamp.org/news/how-to-build-rag-ai-agents-with-typescript/](https://www.freecodecamp.org/news/how-to-build-rag-ai-agents-with-typescript/)

## Notes

- OpenAI is a paid service for the tools used in the tutorial, so we use Cohere for free instead
  - Uses **Cohere** instead of OpenAI for embeddings
  - Uses **Cohere** for Agent Pipes instead of OpenAI (configured in Langbase Studio)
- Commands and queries are hard-coded, **there is no user interface**
